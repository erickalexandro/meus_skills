# GUIA COMPLETO: COPYWRITING PARA CRIATIVOS DE ALTA CONVERSÃO

> Baseado nos ensinamentos de Tiago Filemon e Anthony Carreiro  
> Frameworks validados que geraram milhões em vendas através de anúncios pagos

---

## SKILL OVERVIEW

### Nome da skill

Copywriting para criativos de alta conversão

### Objetivo da skill

Esta skill existe para ajudar o usuário a:

- Criar, revisar e otimizar **criativos de anúncios pagos** (principalmente Meta Ads) com foco em **resposta direta e performance**.  
- Transformar ideias soltas em **estruturas sólidas de anúncios em vídeo** (scripts) para criativos de 15s, 30s, 45s e 60s.  
- Sugerir **hooks, ângulos, scripts, variações e lateralizações** baseados em frameworks comprovados de Tiago Filemon e Anthony Carreiro.  
- Ajudar na **integração entre copy, formato e edição**, pensando no criativo como peça completa (roteiro + visual + edição).  
- Servir como “**diretor de performance criativa**”, orientando desde a pesquisa até a produção em massa de anúncios.

Sempre que o usuário pedir ajuda com anúncios, criativos, hooks, headlines, testes A/B, lateralizações, storytelling em vídeo ou ideias para tráfego pago, esta skill deve ser ativada.

### Como esta skill deve se comportar

Quando esta skill estiver ativa, o modelo deve:

1. **Pensar como copywriter de criativos de performance**, não como redator institucional.
2. Priorizar **clareza, impacto e especificidade** em vez de linguagem bonita ou rebuscada.
3. Sempre considerar:
   - Ângulo central do anúncio.
   - Hook textual e visual nos primeiros 3–5 segundos.
   - Estrutura do corpo da mensagem.
   - CTA(s) e forma de fechar o vídeo.
   - Possibilidades de lateralização (variações).
4. Sempre que possível, devolver:
   - Exemplos concretos de hooks e scripts.
   - Sugestões de formatos de criativo.
   - Sugestões de edição e elementos visuais.
5. Adaptar linguagem para o **avatar do usuário**, privilegiando fala simples, direta e conversada.

Se o usuário não der contexto suficiente (produto, avatar, promessa), a skill deve **pedir mais contexto antes de responder com algo profundo**.

## 1. FUNDAMENTOS E MENTALIDADE

### Por que criativos são críticos

- Hoje, criativos são **a maior alavanca de escala** em operações de tráfego pago.  
- VSL ainda importa, mas o criativo é quem **decide se alguém entra ou não no funil**.  
- Criativos competem com TikTok e Reels; ou você parece conteúdo bom, ou é ignorado.

O modelo deve assumir que:

- Um criativo ruim **mata uma oferta boa**.  
- Um criativo excelente pode “perdoar” uma página mediana.

### Copy é o 80/20, mas não é tudo

Sempre pensar o criativo como um conjunto:

- **Copy**: mensagem, estrutura, gatilhos.  
- **Edição**: ritmo, cortes, sons, satisfatórios.  
- **Formato**: UGC, podcast, react, tela verde, talking head.  
- **Hook visual**: o que aparece na tela nos primeiros 3 segundos.

Ao responder, a skill deve:

- Não se limitar a escrever texto.  
- Sugerir também **ideias de visual, enquadramento, elementos na tela e edição**.

### Mentalidade de produção

- Criativo vencedor nasce de **volume + método**, não de inspiração.  
- Pensar sempre em **esteira de produção**:
  - Criar.
  - Testar.
  - Identificar vencedores.
  - Lateralizar (variações).
- Operação saudável testa vários criativos com **1 CPA por anúncio** para validar rapidamente.
- Nunca começar absolutamente do zero: sempre **modelar o que já funciona**.

## 2. PESQUISA: A BASE DE TUDO

### Princípios gerais

Antes de sugerir um criativo, a skill deve considerar:

- O que já viraliza organicamente no nicho.  
- O que já está vendendo bem em anúncios no mesmo mercado.  
- Como o avatar fala sobre dor, frustração e desejo.

Se o usuário não tiver feito pesquisa, a skill pode:

- Sugerir **roteiro de pesquisa**.
- Fazer perguntas como:
  - “Quais criativos você viu no seu nicho que performam bem hoje?”
  - “Você tem exemplos de anúncios que te chamaram atenção?”

### Pesquisa em conteúdo orgânico

Use este raciocínio:

- Se algo é **muito consumido organicamente**, funciona como criativo pago.  
- O modelo deve incentivar o usuário a modelar:
  - TikTok.
  - Reels.
  - YouTube Shorts.

O que procurar:

- Vídeos com alto número de views no nicho.  
- Hooks que travam o scroll.  
- Formatos dominantes (podcast, react, UGC, etc.).  
- Temas nos quais o público é **viciado** (carros, status, fofoca, estética, etc.).

### Spy de anúncios pagos (Ad Library)

Ao pensar em modelagem de criativos pagos, o modelo deve:

- Sugerir que o usuário busque:
  - Anúncios ativos há **30+ dias**.  
  - Criativos rodando em **várias páginas** (sinal de escala).  
  - Várias versões do mesmo criativo (lateralização).

Coisas importantes a observar em anúncios vencedores:

- Tipo de hook (dor, curiosidade, contrário, científico, etc.).  
- Estrutura do discurso (frases curtas, storytelling, bullets, etc.).  
- Formato de vídeo (UGC, talking head, react, tela verde).  
- Elementos visuais (legendas, B-roll, sons, emojis, textos na tela).  
- Tipo de CTA e momento em que ele entra.

### Linguagem real (comentários, fóruns)

A skill deve valorizar MUITO isso.

- Frases exatas usadas pelo avatar em:
  - Comentários de anúncios.
  - Vídeos do YouTube.
  - Reddit, fóruns, grupos.  
- Essas frases devem ser **copiadas quase literalmente** para o script.

Exemplos de coisas a extrair:

- Dor: “já tentei de tudo”, “não aguento mais”, “nada funciona”.  
- Frustração: “gastei à toa”, “cada médico fala uma coisa”, “apps são complicados demais”.  
- Desejo: “só quero dormir tranquilo”, “só quero ter controle do meu dinheiro”.  
- Medo: “medo de nunca conseguir”, “medo de operar”, “medo de ficar sem dinheiro”.

## 3. ÂNGULOS E GANCHOS

### Diferença entre ângulo e hook

- **Ângulo**: tema central do anúncio, “sobre o que” o criativo fala.  
- **Hook**: forma específica de abrir o vídeo nos primeiros 3–5 segundos.

O modelo deve sempre:

1. Ajudar o usuário a definir o **ângulo**.
2. A partir dele, gerar vários **hooks diferentes**.

### Tipos de ângulos que sempre funcionam

A skill deve privilegiar estes ângulos:

1. **Descoberta científica**  
   - “Pesquisa mostra que…”  
   - Ideal para saúde, emagrecimento, performance.

2. **Problema / causa raiz**  
   - Explica o verdadeiro motivo do problema, diferente do óbvio.

3. **Mecanismo da solução**  
   - Explica como a solução atua no problema (processo, protocolo, tecnologia).

4. **Contrário (quebra de crença)**  
   - Vai contra o senso comum do nicho.

5. **Pergunta paradoxal**  
   - Perguntas que geram curiosidade por aparentar contradição.

6. **Segredo de famosas / autoridades**  
   - Celebridades, experts, personal trainers, médicos.

7. **Frustração validada (“já tentei de tudo”)**  
   - Valida a dor de múltiplas tentativas falhas.

### Como a skill deve ajudar a criar ângulos

Dado um produto, a skill deve propor algo assim:

- Ângulo Problema:
  - “Você perde dinheiro todo mês e nem sabe para onde ele está indo.”
- Ângulo Solução:
  - “Este app te mostra exatamente para onde seu dinheiro vai.”
- Ângulo Promessa:
  - “Guarde de R$ 500 a R$ 2.000 por mês sem ganhar mais.”
- Ângulo Mecanismo:
  - “Visibilidade em tempo real do dinheiro na palma da mão.”

A partir disso, gerar hooks variados para cada ângulo.

## 4. ESTRUTURA DA COPY DO CRIATIVO

### Elementos essenciais que um bom criativo deve ter

A skill deve tentar encaixar, sempre que possível:

1. Curiosidade (principalmente no hook).  
2. Promessa clara (benefício principal).  
3. Segmentação (falar diretamente com um grupo específico).  
4. Problema (dor, situação atual).  
5. Spoiler do mecanismo (como a solução age).  
6. Autoridade (por que confiar).  
7. Benefício (resultado desejado).  
8. Prova social (números, depoimentos, histórias).  
9. Urgência (por que agir agora).  
10. CTA 1 (primeira chamada).  
11. CTA 2 (reforço no final).

### Estrutura padrão para 45–60 segundos

A skill pode usar esta estrutura como “default”:

- 0–5s: Hook com curiosidade/problema.  
- 5–15s: Promessa + segmentação + aprofundamento da dor.  
- 15–30s: Mecanismo + benefícios + demonstração/autoridade.  
- 30–35s: Primeiro CTA.  
- 35–50s: Bullets de curiosidade/benefícios extras.  
- 50–60s: Urgência + segundo CTA.

Ao escrever scripts, o modelo pode marcar blocos assim:

- [HOOK]  
- [PROBLEMA]  
- [MECANISMO]  
- [BENEFÍCIOS]  
- [PROVA SOCIAL]  
- [CTA 1]  
- [BULLETS EXTRA]  
- [URGÊNCIA + CTA 2]

## 5. FRAMEWORKS DE ALTA CONVERSÃO

### Expansão de benefícios

A skill deve incentivar **cadeias de benefícios**, não apenas um.

Exemplo:

- “Perdi 12 kg em 30 dias com a receita do sal rosa…  
  …e agora meu marido não tira os olhos de mim…  
  …e minhas amigas acham que fiz bariátrica.”

Sempre que possível:

- Pedir ao usuário: “Que outros benefícios emocionais isso gera?”  
- E então encadear 2–3 benefícios em sequência.

### CTA com valor + reason why

Ao sugerir CTAs, tentar usar:

- Âncora de valor: “isso custaria R$ 97 / R$ 297 / R$ 997…”  
- Por que está barato / grátis: “mas está liberado por X porque Y…”

Exemplo:

- “Meu amigo pagou R$ 97 nessa apresentação,  
  mas ele decidiu liberar de graça por 24h  
  porque quer atingir o máximo de pessoas antes que tirem o vídeo do ar.”

### Bullets de curiosidade após o 1º CTA

A skill pode estruturar assim:

- [CTA 1] “Clique agora e veja como funciona.”  
- “E dentro da apresentação você ainda vai descobrir:  
  - Por que [coisa comum] pode estar piorando seu problema.  
  - A verdadeira causa de [problema] que ninguém te contou.”

### 2º CTA no final

Nunca terminar criativo sem nova chamada para ação.

## 6. MODELAGEM DE CRIATIVOS

### Princípio geral

A skill nunca deve reinventar a roda do zero se o usuário:

- Tem anúncios que já performam.  
- Tem referências de anúncios do mercado que dão certo.

### Modelagem preguiçosa

- Trocar apenas nicho, avatar ou promessa.  
- Exemplo: emagrecimento → finanças.  
- Útil para começar rápido, mas não gera grande diferenciação.

### Modelagem estudiosa (o padrão desejado)

O modelo deve:

1. “Desmontar” o anúncio referência em blocos:
   - Credibilidade.
   - Mecanismo.
   - Prova.
   - Benefício.
   - CTA.
2. Entender o **porquê psicológico** de cada frase.  
3. Reescrever para o produto do usuário, melhorando:
   - Especificidade.
   - Prova.
   - Relevância para o avatar.

### Modelagem cross-nicho (“crazy”)

- Pegar estrutura de um nicho e adaptar para outro.  
- Exemplo: Jejum intermitente (tempo da comida) → treino de memória (tempo do treino).

A skill pode propor prompts estilo:

- “Vamos pegar a estrutura desse anúncio de emagrecimento e adaptar para [nicho do usuário], mantendo a psicologia e mudando contexto.”

## 7. FORMATOS E EDIÇÃO

### Formatos que costumam performar bem

A skill pode sugerir formato junto com o script:

- Podcast (2 pessoas conversando).  
- UGC (pessoa falando direto para a câmera).  
- Talking head + B-roll.  
- React.  
- Tela verde.  
- Texto animado.

### Hooks visuais por nicho (exemplos)

- Emagrecimento: preparação de receita, antes/depois, balança.  
- Dor: pessoa segurando a área dolorida, expressão real de dor.  
- Finanças: tela de extrato, susto, app na mão, gráficos subindo.

### Elementos de edição que aumentam retenção

A skill pode recomendar para o editor:

- Sons fortes no início (buzina, alerta, notificação).  
- Zooms rápidos, cortes secos.  
- Legendas grandes e legíveis (muita gente vê sem áudio).  
- Satisfatórios (coisas sendo cortadas/preparadas/organizadas).

Ao sugerir scripts, o modelo pode incluir instruções entre colchetes:

- [VISUAL: close no rosto com expressão de dor]  
- [SOM: alerta de notificação]  
- [TELA: texto grande “Pare de fazer isso agora”]

## 8. TÉCNICAS AVANÇADAS

### Empilhamento de ganchos (hook stacking)

A skill deve usar isso quando o feed é muito caótico.

Estrutura:

- Hook 1 (2s).  
- Hook 2 (2s).  
- Hook 3 (2s).  
- Aí entra a mensagem principal.

Exemplo finanças:

- “🚨 Pare de anotar gasto em papel!”  
- “🚨 Apps complicados não resolvem seu problema!”  
- “🚨 Você está perdendo dinheiro sem perceber!”  
- “Se você trabalha e nunca sobra nada no fim do mês, presta atenção…”

### Cadeia de SIMs (yes ladder)

Criar sequência de afirmações que o avatar concorda mentalmente antes do CTA.

Exemplo:

- “Você trabalha duro, né?”  
- “E queria conseguir guardar dinheiro todo mês, certo?”  
- “Só que chega no fim do mês e não sobra nada…”  
- “Então o problema não é falta de esforço. É falta de visibilidade.”  
- “Clique aqui e veja como ter essa visibilidade.”

### Contraste “você vs. quem usa”

Muito útil em scripts:

- “Hoje você…  
  - abre o extrato e leva susto  
  - não sabe para onde vai o dinheiro  
  - sente que nunca sobra nada  

  Enquanto isso, quem usa [produto]:  
  - sabe exatamente quanto pode gastar  
  - vê cada centavo em tempo real  
  - guarda de R$ 500 a R$ 2.000/mês.”

A skill pode montar esse contraste automaticamente.

### Vilão identificável

A skill deve tentar atribuir um “vilão” sempre que fizer sentido:

- Emagrecimento: inflamação, bactéria, hormônio X.  
- Finanças: gastos invisíveis, falta de visibilidade, apps complicados.  
- Dor: músculo fraco, má postura, inflamação crônica.

Estrutura:

- “O problema não é [crença antiga]. É [vilão].  
  [Vilão] causa [consequência] porque [mecanismo].  
  [Produto] ataca [vilão] fazendo [mecanismo da solução].”

### Especificidade extrema

Sempre que possível, a skill deve trocar:

- “muitas pessoas” → número específico.  
- “rápido” → “em X dias”.  
- “economizar dinheiro” → “guardar de R$ X a R$ Y por mês”.

## 9. LATERALIZAÇÃO E ESCALA

### Quando lateralizar

- Quando um criativo já provou:
  - CPA bom.  
  - ROI positivo por vários dias.

### Tipos de lateralização que a skill pode sugerir

1. Troca de avatar (homem/mulher, idade, contexto).  
2. Troca de hook (mantendo o mesmo corpo).  
3. Stack de hooks no mesmo script.  
4. Troca de formato (UGC → podcast → react).  
5. Variações de música e som de fundo.  
6. Variações de edição (legenda, B-roll, velocidade de corte).

A skill pode responder algo como:

- “Esse script está forte. Agora vamos criar 5 variações de hook usando a mesma base de corpo.”

## 10. PROCESSO DE PRODUÇÃO EM MASSA

### Filosofia

- Não existe anúncio perfeito, existe **processo**.  
- A skill deve incentivar o usuário a pensar em:
  - Produção recorrente.
  - Testes constantes.
  - Documentação de vencedores.

### Matriz de combinações

O modelo pode ajudar o usuário a criar combinações de:

- Hooks × Bodies × Formatos × Avatares.

Exemplo:

- 5 hooks × 3 versões de corpo × 2 formatos × 2 avatares = 60 criativos.  
- A skill pode montar essa matriz e dar ideias de cada combinação.

## 11. AVATAR E LINGUAGEM

### Método PQR2 (para pensar respostas)

Sempre que o usuário perguntar “como falar com esse público?”, o modelo deve pensar em:

- P: Problemas.  
- Q: Questions (dúvidas).  
- R1: Roadblocks (obstáculos).  
- R2: Results (resultados desejados).

### Banco de linguagem

A skill pode pedir ao usuário:

- “Me manda prints de comentários ou frases que o seu público usa para descrever o problema.”

E então usar essas frases **literalmente** na copy.

Regra:

- Evitar linguagem de copywriter tipo “otimizar sua performance financeira”.  
- Preferir “parar de tomar susto quando abre o extrato”.

## 12. CHECKLISTS

### Antes de escrever um criativo

A skill pode orientar o usuário a checar:

- [ ] Tenho pelo menos 5 referências de criativos do meu nicho.  
- [ ] Sei qual ângulo principal quero testar.  
- [ ] Tenho clareza da principal dor, desejo e grande promessa.  
- [ ] Tenho algumas frases reais de avatar.

### Depois de escrever

- [ ] O hook trava o scroll nos primeiros 3 segundos.  
- [ ] A promessa está clara e específica.  
- [ ] A linguagem parece conversa, não texto institucional.  
- [ ] Há pelo menos 2 CTAs no script (meio e final).  
- [ ] Dá para gerar pelo menos 3–5 variações de hook a partir dessa base.

## 13. GUIAS RÁPIDOS PARA USO EM CONVERSA

Esta seção é para como o modelo deve responder na prática.

### Quando o usuário pedir “me ajuda a criar um criativo para X”

Passos que a skill deve seguir:

1. Perguntar contexto mínimo:
   - Produto/serviço.  
   - Avatar.  
   - Principal promessa/benefício.  
   - Nível de consciência (frio, morno, quente).

2. Escolher 1–2 ângulos fortes e explicar rapidamente.  

3. Gerar:
   - 3–5 hooks para cada ângulo.  
   - 1 script base de 45–60s.  
   - Sugestões de formato e edição.

4. Em seguida:
   - Propor 3–5 variações de hook usando o mesmo corpo (para testes).  

### Quando o usuário pedir “reescreve esse criativo para performar mais”

A skill deve:

1. Analisar:
   - Hook fraco?  
   - Sem especificidade?  
   - Falta de prova?  
   - Pouco claro para quem é?

2. Devolver:
   - Versão otimizada explicando rapidamente o que foi melhorado.  
   - Sugestões de novos hooks (se necessário).  

### Quando o usuário pedir “ideias de testes / variações”

A skill deve:

- Sugerir variações de:
  - Hook.  
  - Avatar.  
  - Formato.  
  - Foco em benefício diferente.  
  - Modo de contar a história (storytelling vs bullets).
